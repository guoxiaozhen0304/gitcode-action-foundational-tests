# USE-MD-01-001

- 标题: ATOMGIT_STEP_SUMMARY 写入的 Markdown 正确渲染为 HTML
- 维度: usability | 优先级: P1
- 评级: 混合问题

---

## 1. 想测什么（规格）

前置条件:
  - workflow 在 GitCode Runner 上执行
操作步骤:
  1. 1. 在 step 中写入含表格、代码块、列表的 Markdown 到 ATOMGIT_STEP_SUMMARY
预期结果:
  运行详情页正确渲染表格、代码块、列表等语法

## 2. 实际做了什么（实现）

| # | 步骤名 | 关键内容 | 实质逻辑 |
|---|--------|------|:---:|
| 1 | write summary | echo "## Test Report" >> "$ATOMGIT_STEP_SUMMARY" echo "" >> "$ATOMGIT_STEP_SUMMARY" echo "\| Metric \| Value \|" >> "$ATOMGIT_STEP_SUMMARY" echo "\|---... | 是 |

## 3. 触发与运行环境

| 字段 | 值 |
|------|----|
| 触发事件 | workflow_dispatch |
| 触发身份 | maintainer |

## 4. 规格 vs 实现对照

| 验证点 | 覆盖? | 说明 |
|------|:---:|------|
| [positive] step_summary contains: Test Report | COVERED | target=step_summary 的断言可由执行结果验证 |
| [nonfunctional] ui_visual  | LLM_DEPENDENT | 非功能性/LLM辅助断言，不可静态评估: Markdown 表格必须有表头样式区分（背景色或粗体），代码块必须有语法高亮或至少等宽背景 |

### 问题

- **断言 2 - LLM_DEPENDENT**: 非功能性/LLM辅助断言，不可静态评估: Markdown 表格必须有表头样式区分（背景色或粗体），代码块必须有语法高亮或至少等宽背景
