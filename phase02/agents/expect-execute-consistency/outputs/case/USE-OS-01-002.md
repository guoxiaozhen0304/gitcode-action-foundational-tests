# USE-OS-01-002
- **标题**: runner 上下文返回值精确格式与文档枚举值逐字符一致性
- **维度**: 易用性/兼容性
- **评级**: 断言一致

## 想测什么
记录 runner.os 与 runner.arch 的实际返回值，与 context.md 文档枚举值（Linux、X64）逐字符比对，检查文档是否说明大小写比较规则。

## 做了什么
workflow 输出 `${{ runner.os }}` 和 `${{ runner.arch }}` 值。文档侧做枚举值 diff。
