# USE-RUN-01-003  - **标题**: rerun 上限与 6 小时时限在 UI 的明示（判定方式：llm_assisted）   - **维度**: usability   - **评级**: 断言一致

## 想测什么

重跑不可用时按钮应有 tooltip 明示原因；运行详情页应显示已重跑次数与剩余次数

## 做了什么

- 1. 对同一失败运行连续重跑直至达到上限
- 2. 观察重跑按钮置灰时的悬停提示与运行详情页信息
- 3. 对超过 6 小时的运行观察按钮状态与提示

- - [正向] 达到 3 次上限后按钮置灰且悬停提示已达最大重跑次数
- - [正向] 超过 6 小时的运行按钮置灰且悬停提示时限原因
- - [非功能] 运行详情页应显示当前已重跑次数
