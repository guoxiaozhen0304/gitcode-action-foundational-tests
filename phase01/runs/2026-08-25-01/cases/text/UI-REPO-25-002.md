# UI-REPO-25-002

## 基本信息
- **ID**: UI-REPO-25-002
- **维度**: usability
- **优先级**: P1
- **标题**: 分支切换器搜索与切换体验
- **Intent 溯源**: INTENT-USE-006

## 测试目的
验证仓库浏览场景的分支选择/切换器支持搜索过滤，且切换分支后页面内容正确刷新。

## 前置条件
- 用户已登录
- 目标仓库存在多个分支

## 操作步骤
1. 打开仓库首页 `/{owner}/{repo}`
2. 点击分支名称旁的下拉按钮（分支切换器）
3. 等待分支列表弹出
4. 在搜索框输入某分支名关键字
5. 点击筛选出的分支进行切换
6. 等待页面刷新

## 预期结果
- 分支列表正常弹出并展示仓库所有分支
- 搜索输入后列表即时过滤
- 切换分支后文件树与 README 渲染对应该分支内容
- URL 中分支参数随之变更
