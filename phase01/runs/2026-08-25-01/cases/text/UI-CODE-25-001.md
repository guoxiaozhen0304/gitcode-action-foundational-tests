# UI-CODE-25-001

## 基本信息
- **ID**: UI-CODE-25-001
- **维度**: usability
- **优先级**: P2
- **标题**: 代码查看页行内评论与锚点分享体验
- **Intent 溯源**: INTENT-USE-011

## 测试目的
验证代码文件查看页支持点击行号生成锚点链接，且行内评论（如有）可正常渲染。

## 前置条件
- 用户已登录
- 目标仓库存在可查看的代码文件

## 操作步骤
1. 打开某代码文件查看页 `/{owner}/{repo}/blob/main/src/index.js`
2. 等待代码高亮渲染完成
3. 点击第 5 行行号
4. 观察浏览器地址栏是否追加 `#L5` 锚点
5. 检查被点击行是否有高亮样式
6. 复制带锚点的 URL 并在新标签页打开，检查是否自动定位到对应行

## 预期结果
- 点击行号后 URL 追加行号锚点（如 `#L5`）
- 被点击行有视觉高亮
- 通过锚点链接打开页面后自动滚动定位到对应行

## 清理
- 无需特殊清理（teardown.reset: none）
