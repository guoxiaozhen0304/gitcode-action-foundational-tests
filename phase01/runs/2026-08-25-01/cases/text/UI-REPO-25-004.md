# UI-REPO-25-004

## 基本信息
- **ID**: UI-REPO-25-004
- **维度**: completeness
- **优先级**: P1
- **标题**: 分支列表管理与保护规则功能覆盖
- **Intent 溯源**: INTENT-COMP-006

## 测试目的
验证仓库分支列表页能完整展示分支信息，且分支保护规则设置入口可达。

## 前置条件
- 用户已登录且具有仓库管理权限
- 目标仓库存在多个分支

## 操作步骤
1. 打开分支列表页 `/{owner}/{repo}/branches`
2. 等待分支列表加载
3. 检查列表是否展示分支名称、最新提交、更新时间
4. 点击某分支旁的 "设置保护规则" 或 "保护" 按钮/链接
5. 等待保护规则设置页加载
6. 检查可配置项（如禁止强制推送、需要评审等）是否渲染

## 预期结果
- 分支列表完整渲染所有分支
- 保护规则设置入口可正常点击并跳转
- 保护规则表单页面展示可配置选项

## 清理
- 无需特殊清理（teardown.reset: none）
