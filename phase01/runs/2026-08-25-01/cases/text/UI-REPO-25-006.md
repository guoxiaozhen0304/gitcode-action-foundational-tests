# UI-REPO-25-006

## 基本信息
- **ID**: UI-REPO-25-006
- **维度**: completeness
- **优先级**: P1
- **标题**: 仓库 Fork 流程与 Fork 后独立导航
- **Intent 溯源**: INTENT-COMP-009

## 测试目的
验证仓库 Fork 按钮可用，Fork 确认流程完整，且 Fork 后仓库首页可正常导航。

## 前置条件
- 用户已登录
- 目标仓库允许 Fork
- 当前用户尚未 Fork 该仓库（或已有独立命名空间）

## 操作步骤
1. 打开目标仓库首页 `/{owner}/{repo}`
2. 点击 "Fork" 按钮
3. 等待 Fork 确认/选择命名空间页面加载
4. 选择个人命名空间并确认
5. 等待 Fork 完成并自动跳转
6. 检查跳转后页面是否为 Fork 后的仓库首页

## 预期结果
- Fork 按钮可见且可点击
- Fork 确认页展示可选命名空间列表
- Fork 完成后页面跳转至 `{user}/{repo}` 新仓库首页
- 新仓库文件树与原始仓库一致

## 清理
- 无需特殊清理（teardown.reset: none）
