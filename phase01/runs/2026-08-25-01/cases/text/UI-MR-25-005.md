# UI-MR-25-005

## 基本信息
- **ID**: UI-MR-25-005
- **维度**: completeness
- **优先级**: P0
- **标题**: Merge Request 合并后页面锁定与状态展示
- **Intent 溯源**: INTENT-COMP-004

## 测试目的
验证已合并的 MR 详情页能正确展示 "已合并" 状态，且页面元素（如合并按钮）处于锁定或隐藏状态，评论区仍可访问。

## 前置条件
- 用户已登录
- 目标仓库存在至少一条已合并的 MR

## 操作步骤
1. 打开已合并 MR 详情页 `/{owner}/{repo}/pull/{mr_iid}`
2. 等待页面加载
3. 检查页面顶部状态标签
4. 检查合并按钮是否消失或置灰
5. 滚动至评论区，确认仍可查看历史评论

## 预期结果
- 页面明确展示 "已合并" 或 "Merged" 状态标签
- 合并按钮不可见或已禁用
- 评论区与 diff 历史仍可正常浏览

## 清理
- 无需特殊清理（teardown.reset: none）
