# UI-USER-25-001

## 基本信息
- **ID**: UI-USER-25-001
- **维度**: usability
- **优先级**: P1
- **标题**: 用户工作台通知中心读取与批量操作
- **Intent 溯源**: INTENT-USE-008

## 测试目的
验证用户工作台通知中心页面能正常加载通知列表，并支持单条或全部已读操作。

## 前置条件
- 用户已登录
- 当前账号存在未读通知

## 操作步骤
1. 打开通知中心页 `https://gitcode.com/dashboard/notifications`
2. 等待通知列表加载
3. 检查未读通知是否带有高亮/红点标识
4. 点击单条通知的 "标记已读" 按钮或链接
5. 等待状态更新
6. 检查 "全部已读" 入口是否可用并点击

## 预期结果
- 通知列表完整渲染，未读通知有视觉区分
- 单条标记已读后该通知状态变更为已读样式
- 全部已读操作后列表中未读标识消失

## 清理
- 无需特殊清理（teardown.reset: none）
