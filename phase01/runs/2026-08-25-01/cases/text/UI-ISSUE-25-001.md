# UI-ISSUE-25-001

## 基本信息
- **ID**: UI-ISSUE-25-001
- **维度**: usability
- **优先级**: P0
- **标题**: Issue 创建时空标题异常提示验证
- **Intent 溯源**: INTENT-USE-001

## 测试目的
验证 Issue 创建表单在标题为空时的异常提示是否友好、明确，符合可用性要求。
已有用例 UI-ISSUE-01-002 仅覆盖正向路径；本用例补充异常路径。

## 前置条件
- 用户已登录
- 已定位到目标仓库

## 操作步骤
1. 打开仓库 Issue 列表页 `/{owner}/{repo}/issues`
2. 点击 "新建 Issue" 按钮
3. 在正文输入框填入内容，但将标题留空
4. 点击 "新建 Issue" 提交按钮
5. 观察页面反馈

## 预期结果
- 页面未跳转，仍停留在创建表单
- 标题输入框附近出现明确错误提示（如 "标题不能为空"）
- 已填写的正文内容保持不丢失

## 清理
- 无需特殊清理（teardown.reset: none）
