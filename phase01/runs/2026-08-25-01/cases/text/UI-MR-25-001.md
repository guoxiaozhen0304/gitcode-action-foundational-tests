# UI-MR-25-001

## 基本信息
- **ID**: UI-MR-25-001
- **维度**: usability
- **优先级**: P0
- **标题**: Merge Request 创建时分支选择与差异预览可用性
- **Intent 溯源**: INTENT-USE-003

## 测试目的
验证 MR 创建页的分支选择器可正确切换源/目标分支，且 diff 预览区域能即时渲染差异内容。
已有用例 UI-MR-01-002 仅覆盖正向创建路径；本用例补充分支选择与 diff 预览交互。

## 前置条件
- 用户已登录
- 目标仓库存在至少两个有差异的分支

## 操作步骤
1. 打开分支对比页 `/{owner}/{repo}/compare/main...feat-branch`
2. 等待页面加载 diff 预览区域
3. 检查源分支和目标分支显示是否正确
4. 若页面支持切换分支，尝试切换源分支并观察 diff 区域刷新
5. 检查 diff 区域是否渲染文件差异列表

## 预期结果
- 页面顶部正确展示源分支与目标分支名称
- diff 预览区域加载完成并展示文件差异概览
- 分支切换后 diff 区域内容随之更新（若支持）
- 无 diff 时页面给出友好空状态提示（如 "没有差异"）

## 清理
- 无需特殊清理（teardown.reset: none）
