# UI-ORG-25-001

## 基本信息
- **ID**: UI-ORG-25-001
- **维度**: completeness
- **优先级**: P1
- **标题**: 组织设置与仓库级集成配置页面核心功能可达性
- **Intent 溯源**: INTENT-COMP-008

## 测试目的
验证组织/团队设置页的核心菜单（成员、仓库、集成、权限）可正常加载，且各配置子页面入口可达。

## 前置条件
- 用户已登录且属于至少一个组织/团队
- 当前用户在组织中具有管理权限

## 操作步骤
1. 打开组织设置页 `https://gitcode.com/ghp-org/{org}/settings`
2. 等待页面加载
3. 检查左侧或顶部设置菜单是否展示（概览、成员、仓库、应用集成等）
4. 依次点击 "成员管理"、"仓库列表"、"应用集成" 等菜单项
5. 观察各子页面是否正常加载

## 预期结果
- 组织设置页加载成功，无 404 或空白页
- 设置菜单完整展示可配置项
- 各子页面切换后内容正确渲染

## 清理
- 无需特殊清理（teardown.reset: none）
