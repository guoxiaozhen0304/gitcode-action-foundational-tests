# UI-MR-25-006

## 基本信息
- **ID**: UI-MR-25-006
- **维度**: completeness, usability
- **优先级**: P2
- **标题**: 合并冲突时 Web 冲突解决入口与状态提示覆盖
- **Intent 溯源**: INTENT-COMP-012

## 测试目的
验证当 MR 存在冲突且平台支持 Web 冲突解决时，详情页能展示 "使用 Web 编辑器解决冲突" 入口，并正确提示冲突文件列表。

## 前置条件
- 用户已登录且具有仓库写权限
- 目标仓库存在一个存在冲突且支持 Web 冲突解决的 MR

## 操作步骤
1. 打开存在冲突的 MR 详情页 `/{owner}/{repo}/pull/{mr_iid}`
2. 等待页面加载
3. 检查合并区域提示文案
4. 检查是否存在 "使用 Web 编辑器解决冲突"、"Resolve conflicts" 或类似按钮/链接
5. 若存在，点击该入口
6. 等待 Web 冲突解决编辑器加载
7. 检查冲突文件列表是否展示

## 预期结果
- MR 详情页明确提示存在冲突
- 如平台支持，提供 Web 冲突解决入口按钮/链接
- Web 编辑器页面加载后展示冲突文件列表与冲突标记

## 清理
- 无需特殊清理（teardown.reset: none）
