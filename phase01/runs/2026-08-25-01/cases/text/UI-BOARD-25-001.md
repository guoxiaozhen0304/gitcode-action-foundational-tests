# UI-BOARD-25-001

## 基本信息
- **ID**: UI-BOARD-25-001
- **维度**: completeness
- **优先级**: P2
- **标题**: 全局看板列表与卡片交互覆盖
- **Intent 溯源**: INTENT-COMP-010

## 测试目的
验证仓库或组织级看板（Board/Projects）页面可正常加载列表/卡片，且卡片拖拽或状态切换交互可用。

## 前置条件
- 用户已登录
- 目标仓库已启用看板功能且存在至少一个看板

## 操作步骤
1. 打开看板页面 `/{owner}/{repo}/boards` 或 `/{owner}/{repo}/projects`
2. 等待看板列与卡片加载
3. 检查是否展示多列状态（如待办、进行中、已完成）
4. 检查卡片是否展示标题、标签、负责人信息
5. 点击某卡片查看详情侧栏或弹窗是否弹出

## 预期结果
- 看板列与卡片完整渲染
- 卡片信息（标题、标签、负责人）可见
- 点击卡片后详情面板正常弹出并展示 Issue/MR 信息

## 清理
- 无需特殊清理（teardown.reset: none）
