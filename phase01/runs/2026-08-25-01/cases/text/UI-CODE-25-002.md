# UI-CODE-25-002

## 基本信息
- **ID**: UI-CODE-25-002
- **维度**: completeness
- **优先级**: P2
- **标题**: 代码 Blame 视图与 Raw 文件查看可达性
- **Intent 溯源**: INTENT-COMP-011

## 测试目的
验证代码文件查看页的 Blame 和 Raw 查看入口可正常访问，且对应页面内容正确渲染。

## 前置条件
- 用户已登录
- 目标仓库存在可查看的代码文件

## 操作步骤
1. 打开某代码文件查看页 `/{owner}/{repo}/blob/main/README.md`
2. 等待页面加载
3. 点击 "Blame" 或 "追溯" 按钮/标签
4. 等待 Blame 视图加载
5. 检查每行代码旁是否展示最近提交作者与时间
6. 返回文件查看页
7. 点击 "Raw" 或 "原始文件" 按钮
8. 等待纯文本内容页加载

## 预期结果
- Blame 视图正常加载，每行展示作者、提交 SHA、时间信息
- Raw 页面直接展示文件原始文本内容（无 HTML 装饰）
- Raw 页面 URL 通常包含 `/raw/` 路径段

## 清理
- 无需特殊清理（teardown.reset: none）
