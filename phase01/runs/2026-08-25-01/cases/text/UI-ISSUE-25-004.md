# UI-ISSUE-25-004

## 基本信息
- **ID**: UI-ISSUE-25-004
- **维度**: completeness
- **优先级**: P0
- **标题**: Issue 标签与里程碑绑定功能
- **Intent 溯源**: INTENT-COMP-002

## 测试目的
验证 Issue 详情页或侧边栏的标签、里程碑选择器可正常展开、搜索并绑定到当前 Issue。

## 前置条件
- 用户已登录
- 目标仓库已创建至少一个标签和一个里程碑

## 操作步骤
1. 打开某 Issue 详情页 `/{owner}/{repo}/issues/1`
2. 点击标签区域的下拉/编辑按钮
3. 在弹出的标签列表中选择一个标签
4. 点击里程碑区域的下拉/编辑按钮
5. 选择一个里程碑
6. 等待页面更新

## 预期结果
- 标签下拉正常展开并展示仓库已有标签
- 选择后 Issue 头部或侧边栏显示新绑定的标签
- 里程碑下拉正常展开并展示已有里程碑
- 选择后 Issue 显示对应里程碑

- 无需特殊清理（teardown.reset: none）
