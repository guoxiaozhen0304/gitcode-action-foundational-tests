# UI-MR-25-004

## 基本信息
- **ID**: UI-MR-25-004
- **维度**: completeness
- **优先级**: P0
- **标题**: Merge Request 差异对比页代码评审评论完整渲染
- **Intent 溯源**: INTENT-COMP-003

## 测试目的
验证 MR 的 Files changed / diff 页面能完整渲染代码差异，并支持在 diff 行上添加行评论。

## 前置条件
- 用户已登录
- 目标仓库存在至少一条有代码变更的 MR

## 操作步骤
1. 打开 MR 的 diff 页面 `/{owner}/{repo}/pull/{mr_iid}/files`
2. 等待 diff 内容加载完成
3. 检查文件差异列表是否完整渲染
4. 在某行代码旁点击评论图标或行号
5. 在弹出的评论框输入 "diff 行评论测试"
6. 点击提交
7. 等待评论渲染

## 预期结果
- diff 页面完整展示变更文件列表与具体代码差异
- 行评论输入框正常弹出并可填写
- 提交后评论锚定到对应代码行并可见

## 清理
- 无需特殊清理（teardown.reset: none）
