# UI-USER-25-002

## 基本信息
- **ID**: UI-USER-25-002
- **维度**: usability
- **优先级**: P2
- **标题**: 个人设置页表单保存与即时反馈
- **Intent 溯源**: INTENT-USE-010

## 测试目的
验证个人设置页的表单修改后能正常保存，并在保存后给出即时成功提示。

## 前置条件
- 用户已登录

## 操作步骤
1. 打开个人设置页 `https://gitcode.com/profile` 或 `/settings/profile`
2. 等待表单加载
3. 修改昵称或简介输入框内容（追加 "-UI-Test"）
4. 点击 "保存" 或 "更新资料" 按钮
5. 等待页面反馈
6. 刷新页面，检查修改是否持久化

## 预期结果
- 保存按钮可正常点击
- 保存后页面出现成功提示（如 Toast 或横幅 "保存成功"）
- 刷新页面后修改内容保持
