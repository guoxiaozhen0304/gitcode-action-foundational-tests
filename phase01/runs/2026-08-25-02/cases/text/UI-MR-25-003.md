# UI-MR-25-003

## 基本信息
- **ID**: UI-MR-25-003
- **维度**: completeness
- **优先级**: P0
- **标题**: Merge Request 关闭与重新打开状态流转
- **Intent 溯源**: INTENT-COMP-004

## 测试目的
验证 MR 详情页的关闭、重新打开操作可用，且状态变更后页面即时反馈正确。

## 前置条件
- 用户已登录且具有 MR 操作权限
- 目标仓库存在至少一条未合并的开放 MR

## 操作步骤
1. 打开某开放 MR 详情页 `/{owner}/{repo}/pull/{mr_iid}`
2. 点击 "关闭" 或 "Close" 按钮
3. 等待页面状态更新
4. 检查页面是否出现 "重新打开" 或 "Reopen" 按钮
5. 点击 "重新打开" 按钮
6. 等待页面状态更新

## 预期结果
- 点击关闭后，MR 状态变更为 "已关闭" 或 "Closed"
- 页面上出现 "重新打开" 按钮
- 点击重新打开后，MR 状态恢复为 "开放" 或 "Open"
- 状态标签（如 open/closed）同步更新

## 清理
- 无需特殊清理（teardown.reset: none）
