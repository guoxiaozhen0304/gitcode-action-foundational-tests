# UI-MR-25-002

## 基本信息
- **ID**: UI-MR-25-002
- **维度**: usability
- **优先级**: P0
- **标题**: Merge Request 冲突状态交互反馈
- **Intent 溯源**: INTENT-USE-004

## 测试目的
验证当 MR 存在代码冲突时，页面能清晰展示冲突状态，并禁用或隐藏合并按钮，给出可操作的解决指引。
已有用例 UI-MR-01-003 仅覆盖成功合并路径；本用例补充冲突状态。

## 前置条件
- 用户已登录
- 目标仓库存在一个存在冲突的 MR

## 操作步骤
1. 打开存在冲突的 MR 详情页 `/{owner}/{repo}/pull/{mr_iid}`
2. 等待页面加载完成
3. 检查合并按钮区域的状态提示
4. 检查是否有 "解决冲突" 相关入口或提示

## 预期结果
- 页面明确提示存在合并冲突（如 "存在冲突，无法自动合并"）
- 合并按钮置灰或隐藏
- 提供冲突解决指引或 Web 编辑器入口（如有）

## 清理
- 无需特殊清理（teardown.reset: none）
