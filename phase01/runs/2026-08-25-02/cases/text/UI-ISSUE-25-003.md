## 测试目的
验证 Issue 详情页能完整渲染标题、正文、标签、里程碑等核心信息，且评论输入与提交功能可用。

## 前置条件
- 用户已登录
- 目标仓库存在至少一条 Issue

## 操作步骤
1. 打开某 Issue 详情页 `/{owner}/{repo}/issues/1`
2. 检查页面是否渲染标题、正文、创建时间、作者
3. 滚动至评论区
4. 在评论输入框填写 "UI 自动化测试评论"
5. 点击 "评论" 按钮提交
6. 等待页面刷新或评论追加

## 预期结果
- Issue 核心信息（标题、正文、作者、时间）完整渲染
- 评论提交后，新评论即时出现在评论列表末尾
- 评论内容与实际输入一致
