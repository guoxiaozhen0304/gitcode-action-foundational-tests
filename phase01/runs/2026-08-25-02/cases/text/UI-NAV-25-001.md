# UI-NAV-25-001

## 基本信息
- **ID**: UI-NAV-25-001
- **维度**: usability
- **优先级**: P2
- **标题**: 无权限与 404 页面友好提示及返回引导
- **Intent 溯源**: INTENT-USE-012

## 测试目的
验证访问不存在页面或私有仓库时，平台返回的 404/403 页面包含友好文案与返回首页/仓库的引导入口。

## 前置条件
- 用户已登录

## 操作步骤
1. 在浏览器地址栏输入一个不存在的仓库路径 `https://gitcode.com/nonexistent-user-12345/nonexistent-repo-67890`
2. 等待页面加载
3. 检查页面展示的提示文案
4. 检查是否存在返回首页或搜索的链接/按钮
5. （可选）访问一个存在但无权限的私有仓库页面，观察提示差异

## 预期结果
- 页面返回 404 状态或友好提示页（非浏览器默认 404）
- 提示文案包含 "页面不存在"、"找不到仓库" 或类似语义
- 页面提供返回首页、搜索仓库或联系管理员的引导入口

## 清理
- 无需特殊清理（teardown.reset: none）
