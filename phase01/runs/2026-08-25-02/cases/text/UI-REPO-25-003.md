## 基本信息
- **ID**: UI-REPO-25-003
- **维度**: completeness
- **优先级**: P1
- **标题**: 仓库文件在线编辑与预览
- **Intent 溯源**: INTENT-COMP-005

## 测试目的
验证仓库文件查看页支持在线编辑模式切换、内容修改与预览渲染，且提交记录查看入口可达。

## 前置条件
- 用户已登录且具有仓库写权限
- 目标仓库存在可编辑文本文件

## 操作步骤
1. 打开某文件查看页 `/{owner}/{repo}/blob/main/README.md`
2. 点击 "编辑" 按钮进入编辑模式
3. 在编辑器中追加一行文本 "UI 测试编辑内容"
4. 点击 "预览" 查看渲染效果
5. 检查预览区是否正确展示 Markdown 渲染结果
6. 取消编辑或返回文件查看页
7. 点击 "提交历史" 或 "History" 入口

## 预期结果
- 编辑模式正常加载代码/Markdown 编辑器
- 预览模式正确渲染修改后的内容
- 提交历史页面可正常访问并展示该文件的历次提交

- 无需特殊清理（teardown.reset: none）
